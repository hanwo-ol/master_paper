Technical Supplement: Mathematical Derivations and Parameter Optimization for Gait Event Detection

1. Physical Justifications of Spatial Projections and Temporal Window Thresholds

본 보행 분석 파이프라인에서 방향 판단 및 시작점 설정을 위해 활용된 시간/공간적 임계 상수의 물리적·생체역학적 타당성 근거는 다음과 같습니다.

1-1. 보행축 정의용 18프레임 윈도우 (\(t_{\text{start window}}\), \(t_{\text{end window}}\))

모션 캡처 데이터의 수평면(X-Z) 상에서 보행 시작 및 종료 시점의 대표 위치를 계산하기 위해 각 18프레임(60Hz 샘플링 기준 300ms) 크기의 중간값 필터 윈도우를 사용합니다. 300ms는 보행 가속 개시 직전의 안정적인 서 있는 상태(Quiet standing)와 6m 돌파 후 보행 감속 직전의 일정한 전방 자세 궤적을 충분히 캡처할 수 있는 최소한의 시계열 길이로 정의됩니다.

1-2. 출발 원점 결정을 위한 5프레임 윈도우 (\(P_{\text{start}}\))

보행 신호 입력 시작 후 피험자의 초기 골반 기준 좌표를 설정하기 위해 최초 5프레임의 중앙값을 사용합니다. 60Hz 캡처 주파수에서 5프레임은 약 83.3ms에 해당합니다. 이는 인간이 자극에 반응하여 자발적 근수축 운동을 시작할 수 있는 반응 시간의 생리학적 하한선인 ~100–200ms (Luce, 1986)보다 확실하게 짧습니다. 따라서 피험자가 보행 기동 신호를 인지하고 실제 몸을 앞으로 움직이기 이전의 온전한 정적 대기 상태 위치임을 생리학적으로 보장합니다.

1-3. 0.08초(80ms) 뒤꿈치 거리 스무딩 윈도우

Zeni 알고리즘의 입력 변수인 골반 대비 상대적 뒤꿈치 거리 \(D_{\text{heel}}(t)\)의 극값 검출 전에 0.08초 크기의 이동 평균 필터를 사용합니다. 80ms의 이동창은 모션 캡처 센서 트래킹 단계에서 발생하는 10Hz 이상의 고주파 흔들림(Tracking Jitter) 노이즈를 컷오프(Cut-off)하여 가짜 피크(False Peak)를 예방하는 한편, 인간 보행 주기 주파수(보통 1~2Hz 범위)의 근본적인 뒤꿈치 궤적 왜곡을 최소화할 수 있는 적정 노이즈 필터 대역입니다.

1-4. 2cm 골반 돌파 보행 개시 판단 임계값 (\(P_{\text{onset}}\))

정지 상태로부터 보행을 시작하는 최초 움직임 시점(\(t_{\text{onset}}\))을 정의하는 기준은 골반 전방 위치가 \(P_{\text{start}}\) 대비 2cm (\(0.02\text{m}\)) 이상 돌파하는 순간입니다. 2cm 수평 변위는 보행 개시 시 뒤꿈치 이지(Toe Off) 전에 체중을 지지측 발로 이동시키며 신체 무게중심을 앞으로 기울이는 예비 자세 조절(Anticipatory Postural Adjustment, APA) 단계에서 나타나는 전방 무게 이동의 생체역학적 최소 변위 임계 표준(Mancini et al., 2016)과 직접 부합합니다.

2. Loss Function & Constraints for Unsupervised Parameter Optimization

Zeni 알고리즘을 통한 착지 시점(\(t_{HS}\)) 검출에 투입되는 하이퍼파라미터 벡터 \(\theta = (d, r, m_0)\) (\(d\): min_distance, \(r\): prominence_ratio, \(m_0\): min_prominence_m)를 결정하기 위한 무감독 손실함수 식의 구성 근거는 다음과 같습니다.

2-1. 개별 보행 시도(Trial)에 대한 손실 함수 \(L_m(\theta)\)

\[L_m(\theta) = \text{Loss}_{\text{periodicity}, m}(\theta) + \text{Reg}_{\text{count}, m}(\theta) + \text{Reg}_{\text{bounds}, m}(\theta) + \text{Reg}_{\text{balance}, m}(\theta)\]

① Stride 주기성 손실 (\(\text{Loss}_{\text{periodicity}}\))

\[\text{Loss}_{\text{periodicity}, m}(\theta) = \frac{CV(T_{L, m}(\theta)) + CV(T_{R, m}(\theta))}{2}\] * 근거: 파킨슨병 환자의 보행 비대칭성이 변동성을 인위적으로 과대평가하지 않도록 좌/우 보폭 시간의 변동계수(CV)를 완전히 독립적으로 계산한 뒤 평균을 취합니다. Stride 검출 수 \(N < 3\)일 경우 변동성 신뢰도 부족으로 인해 오차 상수 \(P_{\text{fail}} = 2.0\)을 가합니다.

② Stride 횟수 규제화 (\(\text{Reg}_{\text{count}}\))

\[\text{Reg}_{\text{count}, m}(\theta) = \sum_{S \in \{L, R\}} \left( 0.5 \times \max(0, 3 - N_{S, m})^2 + 0.2 \times \max(0, N_{S, m} - 9)^2 \right)\] * 임상적 범위 근거: 6m 직선 구간 통과 시 일반 성인의 생리학적 가동 걸음 수의 최소/최대 경계를 \([3, 9]\) strides (양발 6~18걸음)로 규정합니다. 3 stride 미만은 보행이 비정상적으로 길게 뻗었거나 감지가 누락된 경우이고, 9 stride 초과는 종종걸음 노이즈가 과오 검출된 경우로 판정하여 2차 벌점을 가합니다.

③ Stride 시간 범위 규제화 (\(\text{Reg}_{\text{bounds}}\))

\[\text{Reg}_{\text{bounds}, m}(\theta) = \sum_{S \in \{L, R\}} \left( 1.0 \times \max(0, 0.7 - \mu(T_{S, m}))^2 + 1.0 \times \max(0, \mu(T_{S, m}) - 2.0)^2 \right)\] * 임상적 시간 근거: 인간의 평균적인 보행 주기 시간(Stride Time)은 대개 0.7초에서 2.0초 범위 내에 한정됩니다 (Oberg et al., 1993). 이 범위를 이탈하는 극단적인 시간 템포는 알고리즘 오류로 정의하여 2차 곡선 벌점을 적용합니다.

④ 좌우 대칭성 규제화 (\(\text{Reg}_{\text{balance}}\))

\[\text{Reg}_{\text{balance}, m}(\theta) = 0.1 \times (N_{HS, L, m} - N_{HS, R, m})^2\] * 근거: 한쪽 다리의 궤적 노이즈만 가득 검출되거나 특정 편향이 수렴하여 좌우 검출 개수의 극단적인 불균형이 초래되는 이상 수렴 현상을 물리적으로 억제하기 위함입니다.

3. Recommended Validation Protocol for Unsupervised Loss Function

본 비지도 최적화가 유효한 착지점을 추출했는지 수치적으로 증명하기 위해, 최종 논문 투고 전 수행할 정량적 성능 평측 가이드라인입니다.

  1. 검증 데이터 세트 구성:
    • 대조군(HC) 10개 시도, 환자군(PD) 10개 시도를 무작위로 복사하여 총 20개 시도의 독립 검증 데이터셋을 만듭니다.
    • 모션 비디오 및 뒤꿈치 궤적 가속도 데이터를 참고하여 임상 전문가가 참값 뒤꿈치 안착 시점(Ground Truth, 약 150개 이상 예측)을 프레임 단위로 수동 주석(Annotation) 처리합니다.
  2. 오차 마진 규정:
    • 알고리즘 검출 시점(\(t_{\text{pred}}\))이 수동 라벨 시점(\(t_{\text{GT}}\))을 기준으로 \(\pm 3\) 프레임 (60Hz 기준 50ms) 오차 범위 내에 일치하면 정답(True Positive, TP)으로 판정합니다.
  3. 평가 지표 산출:
    • 정밀도 (Precision): \(\frac{TP}{TP + FP}\)
    • 재현율 (Recall): \(\frac{TP}{TP + FN}\)
    • F1-score: \(2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}\)
    • 비지도 전역 최적 파라미터 \(\theta^*\)를 일괄 대입하여 산출한 F1-score 지표를 투고 논문의 방법론 섹션에 추가 이식하여 비지도 모델 최적화의 타당성 검증을 완결합니다.
